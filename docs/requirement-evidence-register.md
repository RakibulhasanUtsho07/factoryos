## Status key

- **Implemented (bounded):** documented backend contract and relevant automated evidence exist for the explicitly stated scope.
- **Partial:** foundational code/tests exist, but end-to-end, external adapter, policy-owner or product acceptance is outstanding.
- **Not implemented / not verified:** a cited document explicitly identifies the workflow as not delivered, or the current repository evidence is insufficient to assert it.
- **Formal sign-off pending:** final source copies are available in Library and hash-pinned in the manifest, but controlled approval metadata/source-of-record and direct P0/P1 acceptance evidence still need owner review.
